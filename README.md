# 【企画書】専門部1_謎解き【Vantan文化祭2026】


## 企画タイトル
**【謎解き＋探索】クロノス-ログ**
<br>

## 企画内容
4階～6階のあちこちにQRコードを配置して、  
読み込むとWebページに飛んで謎解きの問題や問題のヒントが出題される。  
問題を解いて、クリアを目指す。  
<br>

## 企画詳細  
- 10問程度を想定
- 各階に様々なところに、QRコードを配置する。(教室内や混雑しそうな場所は避ける)
- 受付用のメインQRコードは、各階の目に入りそうなところに設置して、ログインをしてもらってスタート
- メンバーはその辺にふらつててもいいので、プレイヤーにヒントを出したり、案内をする。
- クリア後に、景品か得点を用意したい。隠しステージなのでも容易したい。
- フロントエンド：HTML、CSS、JS
- バックエンド：検討中
<br>

## 企画テーマ
![謎解き](./images/謎解きのテーマ.png)
<br>
### 導入
- プレイヤーの設定：時空の探索者
- 時空の探索者となって、各時代の問題を解決しよう！

### 各層のテーマ
- 6階：未来 --> 記憶の売買する世界
  - NPCの大切な記憶が奪われてしまった。
  - 記憶をアップロードされる前に取り戻せ。

- 5階：現在 --> SNSとAIが普及した世界
  - 過保護なAIにSNSのアカウントを奪われてしまった。
  - クロノスを倒して、アカウントを取り戻せ。

- 4階：過去 --> 書物の世界
  - 一子相伝の大事な巻物が盗まれてしまった。
  - (仮)五右衛門を倒して巻物を取り戻せ

### 問題について
- 各時代で問題傾向を統一したい。
- 時代ごとで物語が完結するイメージ
- 各層で３問+ボス1問
